# Agent guide

This repository is the Breathe Mongolia public website. Read [architecture](docs/architecture.md) for the data flow, [development](docs/development.md) for setup and verification, and [review notes](docs/project-review.md) for known follow-ups before making broad changes.

## Work in this repository

- This is a Next.js 14 **Pages Router** application using React 18 and TypeScript. Add routes under `pages/`; do not assume an App Router layout.
- Trace a feature from its `pages/` entry point to `components/`, then to `lib/graphql-api/queries/` or `lib/air-pollution-map/` as needed. Keep changes close to that feature.
- Content comes primarily from WordPress through `lib/graphql-api/api.ts`. Most pages use `getStaticProps` with incremental regeneration; dynamic routes also define `getStaticPaths`. Preserve the route's data loading and `revalidate` behavior when editing it.
- English (`en`) and Mongolian (`mn`) are both supported; `mn` is the default. Update both `public/locales/en/` and `public/locales/mn/` when adding UI copy. For WordPress fields, follow the existing `getTranslated` pattern and pass the route locale in server-side code.
- `graphql/generated.ts` is generated by `yarn generate` from the remote schema in `codegen.yaml`. Do not hand edit generated types. Code generation needs network access and a reachable schema.
- Styling uses Tailwind utilities and global SCSS in `styles/`. Follow nearby component patterns. Global stylesheet imports belong in `pages/_app.tsx`.
- Do not copy values from `.env.local` or map API configuration into documentation, logs, or new client code. `NEXT_PUBLIC_` values are exposed to browsers. Treat changes to sensor API access as integration work requiring a review of where requests run.

## Verification

- For a docs-only edit, check links and review the diff.
- For code edits, run the narrowest relevant check first: `yarn test --runInBand` for Jest, `yarn e2e` for Playwright against a running site, and `yarn lint` where applicable. `yarn build` fetches live WordPress content and may call external sensor APIs, so it requires working external services.
- Playwright defaults to `http://localhost:9000`; set `APP_URL` to test another server. The `yarn dev` script serves port 9000 after code generation. `yarn start` serves port 9001.
- Check both `/` (Mongolian) and `/en/` for visible copy or navigation changes. A page may need its translation namespace added to `serverSideTranslations`.
- Report checks you actually ran and distinguish local failures from unavailable external services.

## Change boundaries

- Keep unrelated fixes out of a focused task. In particular, avoid regenerating `graphql/generated.ts` or reformatting large files unless required by the change.
- Preserve existing user changes in the worktree.
- If a change touches GraphQL queries, verify the returned fields against their consumers and generated types. If it touches a dynamic route, check both locales, missing content, and fallback behavior.
